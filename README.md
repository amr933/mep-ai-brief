# MEP AI Brief — النشرة اليومية لتطبيقات الذكاء الاصطناعي في الـ MEP

نشرة يومية باللغة العربية تُلخّص أحدث أخبار وتطبيقات الذكاء الاصطناعي في:

- ❄️ هندسة التكييف والتهوية (HVAC)
- 🔥 مكافحة الحريق وأنظمة الحماية
- 🚰 الأعمال الصحية وإدارة المياه
- 🏥 الغازات الطبية في المنشآت الصحية

## 🌐 النسخة الويب

النشرة تُنشر يومياً على GitHub Pages:

**➡️ https://amr933.github.io/mep-ai-brief/**

كل يوم يتم توليد صفحة جديدة + حفظ النسخة السابقة في الأرشيف.

## 📲 تليجرام

تُرسل النشرة أيضاً عبر بوت تليجرام بشكل يومي عند الساعة 08:00 صباحاً بتوقيت مصر.

## ⚙️ كيف تعمل النشرة

1. **البحث**: تجميع أحدث الأخبار من مصادر متعددة لكل تخصص.
2. **التحرير الذكي**: نموذج ذكاء اصطناعي يقوم بفلترة الأخبار، اختيار الأكثر صلة، وكتابة ملخص عربي احترافي لكل خبر مع سطر "لماذا يهمك".
3. **النشر**: توليد صفحة الويب + إرسال رسالة التليجرام.

## 🔧 التشغيل اليدوي

```bash
pip install requests
python scripts/generate_newsletter.py
```

## ☁️ النشر التلقائي (GitHub Actions)

يولّد النشرة يومياً عند الساعة 08:00 بتوقيت مصر ويرفع صفحة الويب تلقائياً.

### الأسرار المطلوبة (Repository Secrets)

في إعدادات المستودع: Settings → Secrets and variables → Actions → New repository secret:

| الاسم | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت `@mepnewsletterbot` |
| `TELEGRAM_CHAT_ID` | معرف الشات (مثال: `7758983309`) |
| `MEP_LLM_API_KEY` | مفتاح واجهة برمجة التطبيقات لنموذج التحرير |

> 💡 ملاحظة: إذا تعذّر الوصول إلى مفتاح التحرير، ستعمل النسخة بالبحث المباشر فقط.
